## Selected projects

### Online retail sales and repeat purchasing

How many customers bought again within a year? I used SQLite to analyse 18,957 sales invoices. Of the 4,293 purchasers with a recorded customer ID, 2,742 (63.9%) bought on at least two distinct invoices. I checked the results of seven SQL queries against separate Python calculations.

[Read the case study](https://github.com/PrashantDes/ai-sales-dashboard/blob/main/docs/sql-case-study.md) · [Inspect the repeat-purchase query](https://github.com/PrashantDes/ai-sales-dashboard/blob/main/sql/online_retail/40_repeat.sql)

### Clinical trial termination analysis

I used Python to study 289,595 interventional trials listed as completed or terminated on ClinicalTrials.gov. Of those, 29,925 (10.3%) were terminated. I grouped the reported reasons for stopping and built a Power BI dashboard to compare termination rates by trial phase and sponsor type.

[Explore the dashboard and findings](https://github.com/PrashantDes/clinical_trial_termination_analysis) · [Read the analysis notebook](https://github.com/PrashantDes/clinical_trial_termination_analysis/blob/main/clinical_trial_termination_analysis.ipynb)

### CarePlus support ticket analysis

Which channels generate the most tickets, and how does demand change from day to day? I wrote Athena SQL queries for both questions and used DAX to track open, resolved, and escalated tickets in Power BI. The report also covers application logs so readers can explore system performance alongside support activity.

[View the dashboard](https://github.com/PrashantDes/careplus-ticket-insights#live-dashboard) · [Inspect the Athena queries](https://github.com/PrashantDes/careplus-ticket-insights/blob/main/data-warehousing-analytics/athena-sql-queries/sql-queries.txt)
